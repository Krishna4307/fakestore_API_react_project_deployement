# 🛒 FakeStore API – E-Commerce Web Application
  #Project Description
    FakeStore API is a React-based e-commerce web application that fetches product data from the FakeStore API and dynamically displays 
    products through an interactive user interface.
    The application allows users to browse products, search for specific items, explore products by category, manage their shopping cart,
    and maintain a wishlist.
    It also includes routing for navigating between different pages and product-related operations such as updating and deleting items.
    This project was developed for practice purposes to strengthen my understanding of React, API integration, state management, routing, and CRUD operations.

# Project Purpose
  This project was developed for learning and practice purposes to improve my React development skills and gain hands-on experience 
    building an interactive e-commerce application.
    
# Features
  * API Integration: Fetches and displays product data dynamically from the FakeStore API.
  * Product Listing: Displays products with their details.
  * Search Functionality: Allows users to search for specific products.
  * Category Filtering: Browse products based on different categories.
  * Add to Cart: Add products to the shopping cart.
  * Remove from Cart: Remove previously added products from the cart.
  * Add to Wishlist: Save favourite products to a wishlist.
  * Remove from Wishlist: Remove products from the wishlist.
  * Dynamic Cart Count: Displays the number of items added to the cart in the navigation bar.
  * Dynamic Wishlist Count: Displays the number of items added to the wishlist in the navigation bar.
  * React Routing: Navigate between different pages using React Router.
  * CRUD Operations: Implemented Read, Update, and Delete operations. Create functionality is not included in this project.

# Technologies Used
  *React.js – Building reusable UI components and managing application state.
  *JavaScript (ES6+) – Implementing application logic and interactive functionality.
  *HTML5 – Structuring the application.
  *CSS3 – Styling and designing the user interface.
  *FakeStore API – Fetching product data.
